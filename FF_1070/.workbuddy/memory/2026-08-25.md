# 2026-08-25 工作笔记

## 按键音听不到（PA 未开）— 已修复
- 根因：`ringplay_keysound_start_default_func`(layout_common.c) 只调 `layout_media_power_amplifier_hold()`（只取消待关 PA，不开 PA），真正开功放的函数是 `layout_media_keytone_prepare()`（内部 `power_amplifier_enable(true)`），但此前只在 home 的"媒体"按钮、图库页调用。导致绝大多数页面按键音无声。
- 修复：按键音 start 回调改为直接调用 `layout_media_keytone_prepare()`，每个按键音都开 PA。
- 功放 = GPIO9，定义 `POWER_AMPLIFIER_PIN 9`(user_gpio.c:264)，由 `power_amplifier_enable()` 控制。

## 功放实时打印 — 已加
- `power_amplifier_enable()`(user_gpio.c:265) 原本仅在值变化时打印 `[audio_trace] PA GPIO9 x->x`。已增强为每次调用打印：`PA GPIO9 req=%d actual=%d prev=%d`（actual 用 `gpio_level_read` 回读真实硬件电平）。
- 抓日志用 `grep audio_trace` 即可看 PA 实时状态，配合 `ui_audio_trace`(按键音/界面切换)、`media_audio_trace`(touch-tone start) 对齐"啪"声与爆音时机。
