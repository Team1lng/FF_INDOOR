# 呼叫录像时退出监控卡住修复

## 问题现象

门口机呼叫后，如果正在铃声播放并开始自动录像，此时点击监控界面的返回 Home 按钮或挂断返回待机按钮，界面不会马上退出，需要等铃声播放结束后才离开监控界面。

## 原因分析

`goto_layout()` 会同步执行当前页面的 `LAYOUT_QUIT_FUNC(camera)`。原来的 camera 退出流程会调用 `ringplay_play_stop()`，该接口内部会等待音频输出 buffer 结束或超时，是阻塞式停止。

因此用户点击退出按钮后，UI 线程会卡在停止铃声流程里，表现为要等铃声结束后才切换页面。

## 修改内容

- 在 `ringplay` 增加 `ringplay_play_stop_async()`，只设置停止标志，不等待音频 buffer 清空。
- camera 的返回 Home、挂断返回待机、页面退出流程改为使用异步停止铃声。
- 新增 `camera_call_ring_cancel()`，退出时统一取消来电铃声状态，避免退出后铃声完成回调继续按来电逻辑处理。

## 影响范围

- 只影响 camera 页面退出时的铃声停止方式。
- 保留原 `ringplay_play_stop()` 阻塞式接口，其他需要等待铃声完全停止的场景不受影响。
- 不修改自动录像保存逻辑。

## 验证方式

```sh
cd FF_1070
make
```

板端验证：

1. 设置来电自动录像。
2. 门口机呼叫后，铃声播放期间马上点击返回 Home，确认界面立即切到 Home。
3. 门口机呼叫后，铃声播放期间马上点击挂断，确认界面立即返回待机。
4. 确认退出后铃声会被停止，不会继续按来电逻辑重复播放。
