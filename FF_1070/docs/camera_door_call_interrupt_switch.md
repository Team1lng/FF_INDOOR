# 监控界面来电切通道 UI 错位修复

## 问题现象

在 CCTV 界面手动进入监控后，如果收到门口机来电，画面会切到 `door1`，但界面上会残留 `CCTV1` 的图标；再点击屏幕后，`CCTV1` 和 `door1` 的图标会同时显示，位置也会错乱。

## 原因分析

来电切通道时，`layout_camera.c` 里只切换了通道状态和顶部通道名，没有统一刷新当前页的按钮布局，也没有把通道选择弹窗重新定位。

同时，`switch / record / capture` 这几个按钮原本只在 CCTV 分支改坐标，切回门口机时没有恢复到门口机坐标，导致旧的 CCTV 位置残留在界面上。

## 修改内容

- 新增 `camera_channel_ui_refresh()`，在来电切换通道后统一刷新页面 UI。
- 来电切换到新通道后，强制关闭通道选择弹窗并重新定位。
- `switch / record / capture` 三个按钮改成双向坐标切换，切回门口机时恢复原位。
- 调整后强制 `lv_obj_invalidate()`，避免旧位置残影。

## 影响范围

- 影响 `layout_camera.c` 的通道切换显示逻辑。
- 不改底层来电、对讲、录制逻辑。

## 验证方式

```sh
cd FF_1070
make
```

板端验证：

1. 进入 CCTV 界面。
2. 触发门口机来电，确认切到 `door1` 后只显示当前通道对应 UI。
3. 点击屏幕，确认不会再把旧 `CCTV1` 图标和 `door1` 图标叠在一起。
